📐 Arity Shop — Wireframe Library

Rule: Wireframe before CSS. Every layout change needs a wireframe for each target viewport before implementation begins.

Target viewports: Mobile 375px (primary) / Tablet 768px / Desktop 1280px

Workflow: Identify issue → Wireframe all viewports → Review → Implement → Screenshot → Compare → Commit

🆕 Start here: 00-template.html — Multi-viewport template with Mobile/Tablet/Desktop tabs
Copy this template for any new page. Shows CURRENT vs PROPOSED at all three viewports with tab navigation.
