Responsive Design Spec

  • Desktop (≥768px) — Labels on left of inputs. 120px label width, right-aligned. Input fills remainder. Gender options inline.
  • Mobile (<768px) — Labels above inputs (stacked). Inputs full-width. 16px font-size for touch targets. Buttons full-width.
  • Card containers — White #fff + hairline border #ebebeb + border-radius: 12px. Replaces grey box.
  • Section titles — 14px / weight 600 / sentence case. Identical on both cards.
  • Labels — 11px / uppercase / grey #6b7280 (desktop). 13px / weight 500 / sentence case (mobile).
  • Inputs — 8px radius / grey idle #f9fafb → white on focus. Focus ring: black border + soft shadow.
  • Buttons — Sentence case. Primary: black fill. Secondary: outline. Hover lift + shadow.
  • Gender — Desktop: label left, options inline with 32px gap. Mobile: label above, options horizontal.
  • Login mobile — Single "Sign in" card with email + password stacked. "Create Account" card below. Matches wireframe 06.
