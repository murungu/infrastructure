Implementation constraints captured by this wireframe

  • Use only data already available from autocomplete: result label, optional product image/link, keyword state, and the existing “view all results” link.
  • Dropdown width follows .search-box; no fixed 280px width.
  • Rows are at least 68px on mobile and 72px elsewhere; the final action is at least 48px.
  • Up/down keys move the visible focus state; Enter selects it; Escape closes the panel.
  • The panel overlays page navigation instead of changing header height.
  • Black, white, and structural greys only. No decorative red, gradients, or drop shadows.
